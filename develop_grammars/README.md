# Develop Grammar

## ANTLR4 online
- Go to [antlr4](http://lab.antlr.org/)

## Navigate to 'develop_grammars' folder
- Inside are two folders
    1. **without_pascal:** a general grammar implementation
        - Open text file
        - In text file is EXAMPLE, LEXER, PARSER
    2. **integrate_pascal:** the grammar refactored to use pascal
        - Open text file
        - In text file is EXAMPLE, PARSER

## Steps:
    1. Copy each into the sections of antlr4, respectively.
    2. Click the green 'Run' button

    - Should see no errors
